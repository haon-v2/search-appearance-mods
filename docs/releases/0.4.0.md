# Appearance Mod Loader 0.4.0 Preview — Download and Restart

Based on **Search v1.0.4** by **Drice Roland / Office Commun and Search’s contributors**. Noah Helms contributes the optional appearance loader and Curve mods. This is an unofficial community preview.

## In-app installation

Starting with this build, **Settings → About → Download and Restart** downloads compatible loader updates, verifies their signed metadata and app bundle, quits normally, replaces the preview, and reopens your saved session. The Search menu’s Check for Updates opens this updater too.

- Download progress and cancellation before verification.
- Ed25519-authenticated release metadata, SHA-256 download verification, app identity/code-integrity checks, and downgrade protection.
- A separate helper waits for the browser to quit. The previous app remains available for rollback if replacement or the launch request fails.
- Your existing preview profile and installed mods stay in place. Save unfinished forms before restarting.
- Updates install only when you click. Use a writable Applications folder; read-only or translocated copies must be moved manually.

**On 0.3.x or earlier, install this build manually once:** quit Search Mod Preview, download and unzip **Search-Appearance-Mod-Loader-macOS-arm64.zip**, then replace **Search Mod Preview.app** in Applications. Future signed compatible releases can install through the app. This release cannot retroactively add an installer to an older running build.

Curve Tabs and Curve Tab Folders remain independent optional packages; neither needs to be reimported. The original Search icon is retained. Official Search.app stays separate.

Apple Silicon, macOS 14+. Ad-hoc signed, not Apple-notarized. The dedicated community release signature does not claim Office Commun’s signing identity. First-time users moving from official Search still need to sign in again; preserving official Search’s sign-ins through an official update requires Drice / Office Commun to integrate and ship the feature.

Tests cover authentication and tampering, wrong app identities, corrupted archives, downgrade rejection, rollback, waiting for the old process, actual helper relaunch, and the existing rail/folder/multi-window/restart checks. Compatibility checks continue every six hours; conflicts or failed tests stop publication.
