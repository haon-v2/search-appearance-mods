# Appearance Mod Loader for Search — 0.1.1 Preview

**Search and its original app icon are by [Drice Roland (@driceroland)](https://github.com/driceroland) / [Office Commun](https://officecommun.com), with Search’s upstream contributors.** Appearance-mod support is a community contribution by **[Noah Helms (@haon-v2)](https://github.com/haon-v2)**. The original MIT notice is preserved; this is not an official or endorsed Search release.

## Icon fix

The loader now explicitly bundles **Search’s original app icon**, generated from the unchanged upstream artwork. Older preview builds used Curve’s icon; 0.1.0 removed that resource but omitted a replacement icon declaration, allowing a generic or cached icon to appear. Version 0.1.1 includes `AppIcon.icns`, declares it in the app bundle, removes the old Curve icon resource, and increments the bundle version.

**The loader and mods remain separate.** No mods are bundled or installed automatically. [Curve Tabs](https://github.com/haon-v2/curve-tabs/releases/tag/v0.1.0) remains an independent optional package and does not change the host app’s icon.

## Install or update

> **First-time setup: expect to log in to all your websites again.** Search Mod Preview uses a separate profile and does not automatically carry over Search’s cookies, active sign-ins, or saved-password access. Your existing Search data and sign-ins remain in the original app. This applies when first switching to the preview; updating an existing preview installation retains its own profile.

1. Download **Search-Appearance-Mod-Loader-macOS-arm64.zip** below (Apple Silicon, macOS 14+).
2. Quit **Search Mod Preview**, unzip the download, and replace your existing **Search Mod Preview.app** with this copy. Keep its name and leave the official **Search.app** in place.
3. Reopen the preview. Its existing preview profile and installed mods are retained.
4. If a Dock shortcut still shows an old cached Curve icon, remove that shortcut from the Dock and drag the updated app back from Finder.

This build is ad-hoc signed, not notarized. If macOS blocks it, use System Settings → Privacy & Security → Open Anyway for this app. Mod installation remains Settings → Appearance → Import Mod… → Enable. No website engine or tab behavior changed in this patch.

Verified the generated icon against the original icon in the installed Search app, checked the bundle’s icon declaration and absence of Curve assets, and verified the app signature and release ZIP. [Loader source and instructions](https://github.com/haon-v2/search-appearance-mods).

The loader’s experimental limitations from 0.1.0 still apply. No upstream issue or pull request has been submitted.
