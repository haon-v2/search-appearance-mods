# Appearance Mod Loader for Search — 0.1.0 preview

**Search is the work of [Drice Roland (@driceroland)](https://github.com/driceroland), [Office Commun](https://officecommun.com), and its upstream contributors. Full credit for the original browser belongs to them.**

I’m Noah Helms ([@haon-v2](https://github.com/haon-v2)). My contribution is **appearance-mod support**: a local package loader, import/enable/disable/remove controls, validation, and generic native appearance capabilities. This is an unofficial community preview built on Search—not a new browser foundation or an official Office Commun release. Search’s MIT license and original copyright notice are preserved.

## Loader only — no mods bundled

This release contains the **mod-enabled host**, named **Search Mod Preview**. A fresh installation has **zero mods installed** and uses Search’s standard appearance.

**[Curve Tabs is a separate optional package and release](https://github.com/haon-v2/curve-tabs/releases/tag/v0.1.0).** You do not need to install it. Other packages can use standard tabs with color themes or configure the host’s generic edge-rail renderer.

## Download and install

> **First-time setup: expect to log in to all your websites again.** Search Mod Preview uses a separate profile and does not automatically carry over Search’s cookies, active sign-ins, or saved-password access. Your existing Search data and sign-ins remain in the original app. This applies when first switching to the preview; updating an existing preview installation retains its own profile.

1. Download **Search-Appearance-Mod-Loader-macOS-arm64.zip** below. Requires an Apple Silicon Mac and macOS 14+.
2. Unzip and move **Search Mod Preview.app** to Applications under its own name. Keep your existing Search app.
3. Open the preview. It is ad-hoc signed, **not notarized**; macOS may require **System Settings → Privacy & Security → Open Anyway** for this app.
4. Download any compatible mod separately, then use **Settings → Appearance → Import Mod… → Enable**.

Installing the loader alone does not enable a mod. Disable/remove restores standard rendering without closing your loaded pages. The preview has its own profile and keychain label and does not automatically migrate your data. Upstream automatic updates are disabled for this preview.

## What API 1 supports

- Bounded local JSON packages with explicit import and activation.
- Light/dark color roles.
- Standard tabs or a configurable top/right edge rail (corner radius, tab length, spacing).
- Corrupt/missing selected packages fall back to standard appearance.
- No executable mod code, browsing-data access, or background mod downloads.

This is not WebExtension or Zen Mod compatibility. New rendering capabilities still require a host update. The unmodified official Search app cannot import these packages yet.

## Validation and limitations

Release build and signature verification passed, as did manifest/persistence tests and isolated native checks for unchanged loaded webviews when switching mods, page clicks, rail selection/drag/close/scroll, resizing, and folded-rail reveal. A fresh-profile check confirmed no mods are installed.

The alternate rail’s accessibility is incomplete, and Search’s inline tab-edit/site-information card and space-switching gestures remain in the standard layout. This is a pre-release for feedback, not a claim of full everyday-browser validation or a guarantee about RAM usage.
