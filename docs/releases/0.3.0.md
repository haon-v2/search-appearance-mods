# Search Appearance Mod Loader 0.3.0

Search is by **Drice Roland / Office Commun and its contributors**. This unofficial contribution by **Noah Helms** adds support for a separately installed **Curve Tab Folders** module, ported from the original Curve browser.

- Folder modules and appearance layouts enable independently: use sidebar folders alone or alongside Curve Tabs.
- Create, rename, collapse, drag tabs into folders, move through tab menus, and remove folders while keeping tabs.
- Folders persist per Search space. Disabling the module retains folder data and open tabs.
- Import/export Curve folder JSON; imported tabs remain asleep until selected. Private tabs stay out of saved folders.
- Bold folder names, right-hand disclosures, indented tabs, and themed dotted guides on child-tab hover.
- Curved rail follows the selected tab’s folder. Existing API 1 mods remain compatible.

The loader ships **no installed mods**. Download [Curve Tab Folders separately](https://github.com/haon-v2/curve-tab-folders/releases/latest), then Settings → Appearance → Import Mod… → Enable. [Curve Tabs](https://github.com/haon-v2/curve-tabs) remains a separate optional mod.

Update an existing preview by quitting and replacing Search Mod Preview.app, preserving its name/profile. First-time users switching from official Search should expect to log in again. Seamless official profile-preserving integration requires Drice / Office Commun to integrate and ship the feature; this is not an official Search update.

Apple Silicon, macOS 14+. Original Search icon retained. Ad-hoc signed, not notarized. Upstream stable version is recorded in UPSTREAM_VERSION. Native app, import, independent selection, persistence, space isolation, rail, and restart regression checks gate publication.
