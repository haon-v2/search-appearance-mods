# Appearance Mod Loader 0.2.1 — optional sidebar with curved tabs

Search and its original app icon are by **[Drice Roland / Office Commun](https://github.com/driceroland/Search) and Search’s contributors**. Appearance support is by **Noah Helms (@haon-v2)**. This is an unofficial community preview.

## Choose either layout

Enable Curve Tabs, then open **Settings → Appearance → Show sidebar with curved tabs**:

- **On:** keep Search’s full-height, resizable sidebar beside the curved top/right rail.
- **Off:** use curved tabs alone for more webpage space.

The choice is saved. Enabling the mod preserves your existing sidebar preference. View → Show Tabs in Sidebar (⇧⌘S) changes the same setting. Both layouts share the same tabs and pages; resizing reserves space for the sidebar and rail. Folding hides both; hovering at the left, top or right edge reveals them.

Based on Search 1.0.3. The existing **Curve Tabs JSON works unchanged** and remains a [separate optional download](https://github.com/haon-v2/curve-tabs). No mods are bundled. This fix lives in the loader’s layout support.

## Update

Download **Search-Appearance-Mod-Loader-macOS-arm64.zip**, quit **Search Mod Preview**, and replace **Search Mod Preview.app** with the unzipped copy. Existing preview data and installed mods remain in place. Do not replace official Search.app. Settings → About also offers this release.

Apple Silicon, macOS 14+. Ad-hoc signed, not notarized. If blocked, use System Settings → Privacy & Security → Open Anyway for this app.

First switching from official Search still requires logging into websites again. Drice / Office Commun would need to integrate and officially sign the loader to deliver it as a normal Search update retaining those sign-ins. No upstream commitment is implied.
