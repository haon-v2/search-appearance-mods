# Appearance Mod Loader for Search — 0.2.0 Preview

**Search and its original app icon are by [Drice Roland (@driceroland)](https://github.com/driceroland) / [Office Commun](https://officecommun.com), with Search’s contributors.** Appearance-mod support is by **[Noah Helms (@haon-v2)](https://github.com/haon-v2)**. This is an unofficial community preview, not an endorsed Search release. The original MIT notice is preserved.

## Search updates, with the loader preserved

- Integrates stable **Search 1.0.3**, including its browser improvements and security fixes.
- Settings → About now checks a separate **compatible-loader update channel**, daily and on demand. Failed checks no longer imply that the preview is up to date.
- Future stable Search releases are checked every six hours in GitHub Actions. Integration, build, manifest validation and native UI checks must succeed before an updated preview is published. Source conflicts and failed checks stop publication for review.
- Existing schema-1 packages remain supported. **No mods are bundled.** [Curve Tabs](https://github.com/haon-v2/curve-tabs) remains a separate optional package.

## Install this update once

**0.1.x cannot update itself: it needs this one-time manual upgrade.** Download **Search-Appearance-Mod-Loader-macOS-arm64.zip**, quit **Search Mod Preview**, unzip and replace the existing **Search Mod Preview.app**. Keep its name and leave official **Search.app** in place. Reopen; your preview profile and installed mods remain in place.

From this version onward, **Settings → About → Download update** opens a compatible release when one is available. Installation remains manual because the community preview is ad-hoc signed, not officially signed or notarized. Apple Silicon, macOS 14+. If macOS blocks it, use System Settings → Privacy & Security → Open Anyway for this app.

**First switching from official Search requires logging into your websites again.** Its cookies, sign-ins and saved-password access are not migrated. Drice / Office Commun would need to integrate the feature and ship an official signed Search update to retain those sign-ins through a normal update. No upstream commitment or timeline is implied.

Future compatibility is tested, not universally guaranteed. A major Search change can require adaptation before a compatible loader build becomes available. See the [update policy](https://github.com/haon-v2/search-appearance-mods/blob/codex/appearance-mod-loader/docs/UPDATING.md) and [automation status](https://github.com/haon-v2/search-appearance-mods/actions/workflows/search-updates.yml).
