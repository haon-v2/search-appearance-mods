# Appearance Mod Loader 0.3.1 Preview — Search 1.0.4

Updated to **Search v1.0.4**, with full credit to **Drice Roland / Office Commun and Search's contributors**. Noah Helms contributes the optional appearance loader and Curve mods. This is an unofficial community preview.

## What changed

- Search 1.0.4's browser improvements and security fixes, including multiple windows, native tab groups, custom shortcuts, improved imports, and the optional sidebar on the right.
- Curve Tabs supports the sidebar on either side of the window.
- Curve Tab Folders retains its saved data in the new session format, shares folder definitions across windows, and preserves tab membership when moving within the same space.
- The loader's own update channel stays active after Search's startup changes. The official Search updater cannot overwrite your mod-enabled preview.
- Search's read-only AppleScript dictionary is included. The original Search icon remains, with updated upstream artwork generation.

[Full upstream changes](https://github.com/driceroland/Search/releases/tag/v1.0.4).

## Install the update

Quit **Search Mod Preview** first. Download and unzip **Search-Appearance-Mod-Loader-macOS-arm64.zip**, then replace your existing **Search Mod Preview.app** in Applications. Keep that name and leave official Search.app alone. Your preview profile, installed mod files, tabs and folders stay in place. Existing Curve Tabs and Curve Tab Folders packages need no replacement.

Check **Settings → About → Check for Updates** in the preview, or use this release's download. GitHub labels these community builds as previews; the in-app loader updater includes them. Updates are downloaded and installed manually.

A fresh preview installation remains separate from official Search, so first-time users should expect to sign in again. Seamless integration into official Search requires Drice / Office Commun to accept and ship the feature in their signed app; none is promised.

Apple Silicon, macOS 14+. Ad-hoc signed, not notarized. No mods bundled. [Curve Tabs](https://github.com/haon-v2/curve-tabs) and [Curve Tab Folders](https://github.com/haon-v2/curve-tab-folders) remain independent, optional packages.

Publication is gated on build, package validation, loader update tests and native checks covering both mods, sidebar sizes, multiple windows, cross-window folder moves, native group metadata and restart restoration. Future Search releases are checked on the existing schedule; source conflicts or failed checks stop publication for review.
